# P0：情境式新手引导

**状态：✅ 已完成**

## 内容

第一关地图上方会依次提示玩家亲自切换拖拽工具、连接同色建筑、用选择模式检查住宅预计路线，再自行开始运营；步骤由真实工具、连接和选择状态推进，不会代替玩家施工。引导位于 Canvas 外，不遮挡目标格，支持鼠标、触摸、键盘与屏幕阅读器，并可跳过或从帮助弹窗重新打开。

道路等级、剪刀、路口控制和公交首次开放时只显示当前新机制；施工问题继续通过地图通知与规划问题标记解释。完成和已读机制只保存在本浏览器，减少动态效果设置会关闭相关过渡动画。

## 验收

纯逻辑测试覆盖步骤与机制顺序；浏览器回归覆盖首次显示、控件定位、跳过和重新打开。
