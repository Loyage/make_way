# P1：地图化失败复盘

**状态：✅ 已完成**

## 现状

当前已有前三道路热点和路口/公交报告，但结算数据与地图之间联动不足。

## 计划

- 结算热点、问题路线和路口报告可点击定位。
- 保留整轮累计等待/占用热力图，而不只显示瞬时负荷。
- 对比本次与个人最佳的满意度、P95、建设点和最大排队。
- 根据实际瓶颈生成有限、可解释的建议，不直接替玩家给出完整答案。

## 实现

- 路线送达率、最大住宅排队、前三道路热点和各路口入口报告均可直接定位地图格。
- 运营期间累计住宅等待人秒、道路占用与受阻车秒；从结算进入地图复盘时以紫色和橙红色热力层显示，而非复用瞬时负荷。
- 结算用表格并列展示本次与个人最佳的满意度、P95、建设点和最大排队；旧版个人最佳没有最大排队时显示为空，不影响读取。
- 失败建议最多两条，按未送达路线、住宅累计等待、道路受阻和路口累计排队的实测数据生成，并说明判断依据。
- 地图复盘条提供“返回结算”和“保留设计并修改”；后者只清空本轮车辆、成绩、排队和计时，不清空路网。

## 验收

✅ 失败后玩家可从结算报告一次点击定位主要瓶颈，再一次点击返回原设计继续修改。
