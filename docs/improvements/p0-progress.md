# P0：完整的“继续游戏”能力

**状态：✅ 已完成**

## 内容

规划修改、切关和进入新一天会自动保存最近游玩的关卡、挑战/沙盒模式及当前设计；五日任务同时保存日期、预算、逐日结果、区域开放、建设支出、参考方案分歧和全部已到达检查点。刷新后顶部提供一次点击继续入口。

自动进度采用独立 v1 封装，内部设计继续由 `City.loadDesign()` 严格校验并兼容 v1～v8；多日状态会在独立候选会话中校验所有结果、区域、支出、当前设计和检查点，任何损坏均整体回退到新游戏。设计菜单可只清除此自动进度，不影响逐关手动设计、星级、个人最佳或参考答案解锁。

## 验收

Node 测试覆盖往返、旧设计加载路径、损坏/存储失败和原子回退；玩家浏览器冒烟测试覆盖真实刷新、继续及定向清除。
