# SIM-7：存档无法导出、导入或分享

- 来源：[`dsim.md`](../../../dsim.md)
- 优先级：P2
- 状态：✅ 已完成

## 原现象

设计只存在浏览器 `localStorage`（`STORAGE_PREFIX`），没有导出文件或文本、导入与分享入口。

## 完成内容

- 玩家和管理员共用的「设计存档与分享」菜单可下载版本化 JSON，或复制以 `MWD1.` 开头的文本分享码。
- 可粘贴 JSON / 分享码或选择本地文件，先在独立候选城市中完整解析与严格校验。
- 确认前预览关卡 ID、道路格数、公交线数和预计费用；损坏输入不会部分修改当前城市。
- 分享内容只含规划，不含管理员关卡定义、成绩、车辆、计时或多日结算记录。
- `tests/design-share.test.js` 覆盖 JSON / 分享码往返、迁移和损坏输入拒绝。
