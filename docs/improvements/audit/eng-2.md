# ENG-2：浏览器冒烟测试长期处于「可选且易失效」状态

- 来源：[`dsim.md`](../../../dsim.md)
- 优先级：P1
- 状态：🟡 已精简测试体量，待接入可选 CI

- **现象**：玩家与管理员浏览器脚本需要手动启动服务和本机 Chromium CDP，不在 `node --test tests/*.test.js` 内，因此仍可能长期不执行。
- **当前进展**：已删除重复且资源占用高的六档截图脚本，把玩家冒烟缩为启动、导航、输入、运营控制和两档布局关键路径；管理员冒烟也不再重复完整五日参考链仿真。运行范围已在 README 和 AGENTS.md 中按改动类型限定。
- **建议**：后续把两个精简脚本纳入 CI 的可选 job（`nix shell nixpkgs#chromium` 或环境变量指定浏览器），或增加 npm-free 的启动/清理脚本；至少让「最近一次执行结果」可见。
- **验收**：CI 中出现浏览器 job 的执行日志（允许在无 Chromium 环境下 skip 并显式报告）。
