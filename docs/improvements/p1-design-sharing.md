# P1：设计导入、导出与分享

**状态：✅ 已完成**

## 目标

在不增加服务器端账户的前提下，将当前设计导出为带版本的 JSON 文件或文本分享码，并支持从文件/文本导入后严格校验。

分享内容只包含规划数据，不包含成绩、车辆或管理员关卡定义。导入前预览关卡 ID、道路数、公交线数和预计费用。

## 已实现

- 「设计存档与分享」提供版本化 JSON 下载，以及以 `MWD1.` 开头、可跨浏览器复制的 UTF-8 文本分享码。
- JSON 与分享码使用独立的分享封装版本，只包含关卡 ID 和 `City.serializeDesign()` 规划数据。
- 可粘贴 JSON / 分享码，或选择 `.json` / `.txt` 文件；输入大小、封装字段、格式版本和关卡均会先检查。
- 解析后的设计先载入独立候选城市，由现有设计加载器严格检查地图尺寸、预算、道路、显式连接、引导、信号和公交数据。任何错误均不会修改当前城市。
- 校验通过后显示关卡名称与 ID、道路格数、公交线数和预计建设费用；玩家再次确认后才整体替换。跨关卡导入会切换到目标关卡，多日挑战跨关卡时从第 1 天开始。
- 玩家指南、帮助弹窗、README 和管理员手册已同步；管理员也可用分享码复现玩家方案。

## 验收

- ✅ 合法设计可通过版本化 JSON 和文本分享码往返，并可跨浏览器复制。
- ✅ 文件与文本导入均在确认前展示关卡 ID、道路数、公交线数和预计费用。
- ✅ 恶意、损坏、未知版本、未知关卡和不合法规划输入会整体拒绝，不会部分修改当前城市。
- ✅ `tests/design-share.test.js` 覆盖序列化、JSON / 分享码解析、旧设计迁移、往返和损坏输入拒绝。
