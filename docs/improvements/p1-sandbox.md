# P1：沙盒实验能力

**状态：✅ 已完成**

## 现状

当前沙盒不限时并允许运营中改路，但切换模式会清空设计，且仍沿用关卡预算。

## 计划

- 支持把当前挑战方案复制到沙盒。
- 提供“沿用预算 / 无限预算”选项。
- 支持调整需求倍率、运营速度和持续饱和流量。
- 支持只重置交通状态而保留设计。
- 从沙盒返回挑战时不得静默覆盖挑战方案。

## 已实现

- 模式确认框默认复制当前挑战的完整规划，也可改用空白方案；失败后依次“查看我的城市 → 沙盒 → 进入沙盒”即可在三步内开始实验。
- 沙盒可选择沿用进入时预算或无限预算，并在任务卡调整需求倍率、运营速度及持续饱和流量。
- 持续饱和流量会持续产生需求并忽略目的地输入上限，便于长期观察瓶颈。
- “只重置交通”清空车辆、乘客、排队、统计和计时，但保留全部设计。
- 进入沙盒前的挑战城市单独保留；返回挑战时恢复原对象，从挑战复制出的临时沙盒也不会覆盖挑战自动进度。
- 核心模拟与自动进度已增加沙盒参数回归测试。

## 验收

✅ 玩家可用不超过三步把失败方案带入沙盒验证改造，不损坏原挑战进度。
