# 技术：降低空闲渲染与大地图开销

**状态：⬜ 待实施**

## 现状

玩家端即使处于静止规划状态，也持续通过 `requestAnimationFrame` 执行完整 `updateUI()` 和 Canvas 重绘；运行中的 64×64 可访问网格也可能周期性更新大量 ARIA 标签。

## 计划

- 规划静止时改为事件驱动重绘。
- 运营、视图回弹和短动画期间才保持连续帧。
- DOM 状态、Canvas 和可访问网格分别使用变更签名。
- 可访问网格只更新状态变化的格子，保留完整键盘导航语义。
- 建立 16×12 与 64×64 的可重复性能基线。

## 验收

静止规划时不持续执行完整地图绘制；大地图功能和无障碍播报无回归。
