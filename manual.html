慢行小城游戏指南

这里集中介绍关卡目标、地图操作和交通模拟规则。规划时使用选择、拖拽、剪刀、公交线等工具建设路网与公共交通；开始运营后，小汽车和公交车根据道路连接、容量和路口规则运送居民。

GAME RULES

游戏目标与基本流程

  1. 在预算内把住宅与同色目的地连接起来。道路格必须通过明确的格间连接才能通行，相邻路面不会自动连通。
  2. 关卡按章节展示：前四课位于「道路入门」，后四课位于「城市调度」。先用章节标签切换当前浏览的章节，下方长条只显示该章节的具体关卡；所有关卡仍可自由选择。
  3. 根据住宅人口、居民产生率、门口道路等级、目的地容量和道路承载能力规划道路与路口控制。
  4. 点击「开始运营」后观察车辆运行；在关卡时限内送达目标人数即可胜利。
  5. 运营期间规划锁定。如需调整，停止运营会保留道路设计，但清空本轮车辆、排队、成绩和计时。
MODE 01

选择模式

点击「选择」或按 1 进入。选择模式只负责选区和执行下方按钮，不会因为点击或拖选地图而直接建设、拆除或剪断道路。

选择一个格子

在任意格点击后，蓝色边框标出该格。下方显示坐标和内容类型。再次点击别处会替换原选择。

选择矩形区域

从任意格按住并拖到另一格。起点和终点构成完整矩形，反向、向上或向左拖动同样有效；松手后保留选区。

多格区域信息

显示宽 × 高、总格数、道路格数和内部道路总价。总价按当前道路等级计入；桥梁上的道路与普通道路价格相同。

运营中的车流

运营或暂停时，区域信息显示正在区域内占用或驶入的车辆数，以及选区内住宅的等待车辆数。

选中内容与可用操作

MODE 02

拖拽模式：统一建设、改造与拆除

点击「拖拽」或按 2 进入。从起点按住，依次经过上下左右相邻格。快速斜拖时，系统会补成四向相邻的阶梯路线。拖动期间彩色线框只是预览；松手时才把整条规划一次性应用到地图。

怎样判定拆除

只有满足以下条件，拖拽才进入橙色的拆除状态：

  1. 起点是道路端点（包括桥面道路）；“端点”指它至多只有一条连接，建筑出口连接也计入；
  2. 第一步沿着一条已经存在的连接移动；
  3. 第一步进入的既有道路与起点等级一致。

从只有一个出口的建筑开始、第一步沿已有连接进入道路时也会进入拆除状态。建筑没有道路等级，因此拆除时以第一格道路的等级为准。进入拆除状态后，必须继续沿同等级的既有连接前进；不能隔空拆除，也不能跨等级拆除。

其他情况一律建设

不满足拆除判定的拖动一律是绿色建设状态。建设既会铺设空地，也会为经过的相邻格建立连接；经过已有道路时，会把路面刷新为本次起点等级。因此可用一笔连续拖拽统一改造一条线路。

  • 从已有道路开始：沿用起点道路等级。
  • 从空地或空桥开始：建设支路。
  • 从建筑开始并拖向空地：固定使用支路，因为建筑本身没有等级。
  • 从已有桥面道路开始：沿用该道路等级；桥梁结构始终保留，但桥面道路可以拆除，岸边连接仍需明确拖过。

松手前反向取消

沿刚才经过的路线原路回拖一格，会撤回预览中的最后一段。可以连续退回到起点，再换方向重新规划。由于地图在松手前尚未正式改变，取消不会先扣预算再退款，也不会触发车辆重新寻路。

MODE 03

剪刀模式

点击「剪刀」或按 3 进入。沿道路或建筑出口之间的既有连接拖动，松手后一次性剪断所经连接。

  • 剪刀只删除“连接关系”，不会删除道路格，不改变等级，也不返还预算。
  • 剪断后两块路面即使仍紧挨着，也不能互相通行；切换到拖拽模式沿断口拖过即可重新连接。
  • 剪刀经过没有连接的相邻格时没有效果。
  • 剪切只能在规划阶段进行；运营和暂停期间剪刀工具会被锁定。
  • 剪刀同样支持松手前沿原路线回拖，撤销预览中的最后一段。
MODE 04

公交线路

「公交线」工具只在开放公交功能的关卡可用，第 8 关提供对应教学。点击工具或按 4，从已有道路开始，沿明确连接的道路逐格绘制。线路可以分多次完成：每次松手提交一段，下一次从当前线路末端继续。

  • 第 8 关限制为一条线路；核心和管理界面支持关卡配置多条线路。每条线路拥有独立名称、颜色、道路站点、车辆数和运行方式。普通线路在开始运营前必须回到起点形成闭环；未闭环时开始运营会显示对应线路名称，并保持在规划状态。
  • 开启「原路返回」后，开放线路无需手动画出返程路径。公交到达终点后沿同一道路反向返回起点，返程默认不停站；再次到达起点后恢复正向停站服务。
  • 线路不新建道路，也不能跨越没有明确连接的相邻路面。线路使用中的道路不能拆除，其连接不能剪断。需要局部修改时，点击「反向擦除」，从当前末端沿既有线路反向拖动；只能按绘制顺序逐格擦除尾段。再次点击「取消擦除」或按 Esc 可退出擦除模式，也可删除或清空重画整条线路。
  • 每条线路可投放 1～3 辆公交车，每辆消耗 6 点建设预算，且运营时线路经过的不同道路格不能少于车辆数。删除线路会返还该线路全部公交车辆预算；线路名称、颜色、路径、车辆数、道路站点和原路返回设置会随设计一起保存。
  • 公交车容量为 12 人，以所在道路等级速度的 1.35 倍行驶，并和小汽车共同占用道路位置、遵守容量、自动避让和红绿灯。
  • 线路每次增加路段后，紧邻建筑的新线路道路格会自动设站。选择线路经过的任一道路格，可以为对应线路设置或取消站点；同一格有多条线路时会分别显示各线路的站点窗口。
  • 道路站点服务上下左右相邻的住宅和目的地，不要求建筑另有道路出口连接；公交到站停车，每站先下后上，上下客合计每秒 8 人，有空位时尽量装满。
  • 公交可以集中接走已经产生并正在排队的居民，不经过住宅汽车出口，但不能提前接走尚未产生的居民。公交与小汽车共享住宅总人口，不会重复产生乘客。
  • 只有当该住宅的同色目的地也由该线路的正向站点服务且仍有输入容量时，居民才会上车；上车时立即预约目的地容量。一条线路可以混合服务多种颜色。

线路显示与管理：选择线路道路格后，可在格子信息中分别切换经过该格的各条线路站点，并进入相应线路管理。公交面板可新建、选择、删除、反向擦除尾段或清空重画线路，修改名称、颜色、车辆数和原路返回设置。每条线路都有独立眼睛按钮；关闭显示后线路不会完全消失，而会降低透明度以便聚焦其他线路。彩色线路靠道路行驶方向的右侧绘制，转弯与掉头处连续衔接，细小箭头表示方向；玩家绘制的正向段使用实线，系统生成的原路返程段使用同色虚线，往返方向分列道路两侧。沿线黄点表示站点，建筑左上角「站」表示附近有线路服务；公交车顶人数牌显示「车上人数/12」。

建筑为什么也算道路起点

在连接系统中，住宅和接收建筑都是路径端点。可以直接从建筑按住拖出，不必先在旁边铺一格路面；第一步会同时创建建筑出口连接。

建筑 → 空地

按支路开始建设。即使默认等级选择了干道或快速路，建筑仍没有可继承等级，所以第一条道路固定为支路；之后可用选择模式批量升级。

建筑 → 已连道路

如果建筑只有一个出口，且第一步沿该出口进入道路，则判定为从道路端点向内拆除。多出口建筑不是端点。建筑永远保留，只删除经过的道路格。

建筑旁有路但未连接

视觉相邻不等于连接。此时从建筑拖到路面属于建设，会明确补上出口，并把经过的道路刷新为支路。

建筑信息

规划时，住宅右上角实心气泡显示总人口，目的地右上角描边气泡显示输入容量；运营后两者分别实时显示尚未离开住宅的人数、尚未分配的接收容量。住宅左下角显示居民产生率（+），右下角“待”字气泡显示排队人数。选择建筑可查看剩余、离开、等待、接收和分配数量。

TRAFFIC SIMULATION

一辆车怎样完成出行

  1. 产生需求：每栋住宅按照标注的居民产生率逐步产生居民，直到达到该住宅的总人口。暂时不能出发的居民留在住宅排队。
  2. 选择目的地：居民只前往同色路线的目的地。若有多个可达目的地，车辆选择经过格数最少的一个；目的地设有容量时，已经分配且正在路上的车辆也会占用名额，满额目的地不再接收新车辆。
  3. 驶出住宅：汽车驶出速度只由门口道路等级决定，没有住宅自身的独立出口速率。门口道路的速度与车道位置共同决定车辆何时能离开，建筑出口和第一格道路都必须有可用通行位置。住宅中的等待时间会计入完整通勤时间。
  4. 沿路行驶：车辆逐格寻找通往已选目的地的最短路线。寻路比较道路格数，不比较道路等级或预计耗时，因此更快但更长的道路不一定会被选择。
  5. 等待与抵达：前方车道、路口冲突区或目的地入口不可用时，车辆停在当前安全位置等待。抵达目的地后计入送达人数、释放道路占用，并在对应目的地绽放同路线颜色的庆祝粒子。

颜色代表出行路线：不同颜色的住宅与目的地互不混用。路线必须通过明确连接的道路连续可达，建筑出口也属于连接的一部分。

  • 相反方向分别计算容量。车辆正在驶入时会同时预约目标位置，因此负荷统计包含当前车辆与驶入预约。

  • 下游满载时车辆会在上游等待，不会重叠或越过队列；拥堵本身不直接判负，但会消耗关卡时间并拉低通勤满意度。
  • 「显示道路负荷」使用绿、橙、红边框表示最忙方向的低负荷、接近满载和已满。

路口、自动避让与红绿灯

  • 拥有至少三个实际连接的道路格会成为路口。单格选中路口后，可首先决定是否开启红绿灯；所有设置仅作用于当前路口。
  • 关闭红绿灯时，默认使用「自动让行」：车辆按到达顺序逐辆通过。也可选择「按入口方向优先」，并用上下按钮排列北、东、南、西入口；只要更高优先级入口有待通行车辆，就会优先处理，同一入口内仍按到达顺序通行。两种无灯方式都以道路正常速度的 35% 驶入和驶离。
  • 启用红绿灯并勾选「自动设置信号灯」时，系统依次循环「横向直行 → 横向左转 → 纵向直行 → 纵向左转」。取消勾选后进入手动调度，可添加、删除或排列 1～8 个阶段，并为每个阶段自由选择各入口的直行、左转动作。互相冲突的动作不能保存在同一阶段，每个阶段至少保留一个动作。
  • 自动与手动信号共用每阶段绿灯时长，可设为 2、4 或 6 秒；每阶段之后都有 0.25 秒全红清空期。绿灯车辆按道路原速通过。
  • 右转不纳入自动或手动灯序，始终采用让行通行，但必须避让当前可通行的直行、左转车辆以及已经预约冲突区域的车辆。
  • 信号路口分为四个冲突区；路线不冲突的对向直行、对向左转和部分右转可以同时通行，而不是整格永远只容纳一辆车。
  • 车辆进入路口前会确认出口道路有空间，避免停在路口中央堵住其他方向。出口满载时，车辆在上游等待。
  • 暂停运营时信号倒计时也暂停。信号设置只能在规划阶段修改。

胜负与通勤满意度

  • 在关卡时限结束前送达目标人数即胜利；到达时限仍未完成目标则失败。额外拥堵不会触发其他失败条件。
  • 居民的通勤时间从按产生率进入住宅队列时开始，无论随后乘坐小汽车还是公交，都在抵达目的地时结束，包含住宅排队、途中行驶、停车和路口等待。
  • 结算分档为：8 秒以内「轻松通勤」、15 秒以内「舒适通勤」、25 秒以内「尚可接受」、超过 25 秒「漫长等待」。
  • 满意度统计本轮已经产生的居民：已抵达者按通勤时间分档，尚未抵达者按最低档 30 分计入，并由各档人数按 100、80、60、30 分加权计算。平均通勤时间仍只统计已抵达者。该指标仅用于战绩展示，不影响关卡胜负或预算。

运营期间的规划锁定

  • 点击“开始运营”后，道路建设、升降级、拆除、剪断、信号灯和公交线路设置都会锁定。
  • 运营暂停时计时与车辆停止，但规划仍保持锁定；你仍可选择格子和区域查看实时路况。
  • 需要修改设计时，请点击“停止运营”。现有道路、等级、信号与公交线路设置会保留，车辆、车上乘客、成绩、排队和计时会清空，然后返回规划状态。
  • 游戏已经胜利或失败后也不能修改地图；可查看城市或重新规划。

方向键画布获得焦点后移动格子光标。
空格选择模式选择当前格；拖拽、剪刀或公交线模式设置起点，再用方向键逐格操作，再按空格提交。公交线每次提交一段，后续从线路末端继续；反向擦除模式同样从末端开始。
Esc取消尚未提交的键盘路径；使用公交反向擦除时，同时退出擦除并恢复线路绘制。
P开始运营、暂停或继续；输入框或对话框获得焦点时不触发。
触摸单指按住并移动。选择模式形成矩形；拖拽、剪刀和公交线模式形成路径。松手提交。
