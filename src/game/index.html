      WELCOME, CITY PLANNER

      你的第一座交通小城

      用道路把各个住宅连到同色目的地。一条路线可以包含多个住宅与多个目的地（各自标注输出量/输入量）；车辆选择自由流预计耗时最低的可达目的地。每栋住宅按居民产生率逐步产生出行需求，达到本轮总人数后停止新增；小汽车在门口道路有位置时逐辆出发，驶出速度只由门口道路等级决定，每车 1 人并沿自由流预计耗时最低的道路前进；公交车可在站点集中运送已经产生的居民。

      打开完整游戏指南，查看操作方法、车辆出行和交通模拟规则。首次操作时，地图上方会按实际进度给出四个短步骤；可跳过，并可用本弹窗底部按钮重新打开。选关卡片会显示进度与星级，推荐标记和结算中的下一课建议不会锁定其他关卡。

      • 观察模式（1，默认）：鼠标拖动或手机单指拖动地图，按住 Ctrl 滚动或双指捏合缩放；越过边界松手后会回弹。右上角按钮可缩放或复位。
      • 选择模式（2）：点击选择单格，拖动选择矩形。单格普通道路可进一步选中两端路口之间的整段道路（不含路口格），整段升级、降级或拆除会先显示预计费用与结果，确认后才施工；区域和路线选中后，地图右下角提供只有图标的升级、降级、拆除快捷按钮。只有三岔或十字路口提供调灯操作，住宅可查看人口守恒与预计路径，目的地可查看容量信息。
      • 拖拽模式（3）：从已有道路起拖时，该格等级会成为本次改造目标；经过不同等级的已有道路会预览升降级箭头与松手结果，并在提交时统一到起点等级。从道路起拖到空地时，新路也继承起点等级；从建筑或空地起拖时，新路才默认为支路。普通拖拽继续补充明确连接；回拖可撤销预览，松手时才一次性应用。
      • 剪刀模式（4）：沿既有连接拖动，只剪断连接、保留路面且不返还预算。同格交叉形成路口，相邻路面不会自动连接。
      • 道路只沿拖动经过的上下左右方向相连；河流只能经过桥梁格，但桥面道路和岸边连接都需主动建设。
      • 支路 / 干道 / 快速路每格花费 1 / 2 / 3 点预算，速度为 2.8 / 4 / 5.2 格每秒，每方向分别有 1 / 2 / 3 条车道，路宽逐级增加，车宽保持一致。每条车道可前后容纳 2 辆车，因此每方向容量为 2 / 4 / 6 辆（双向总容量为 4 / 8 / 12 辆，包含驶入预约），后车不能穿过前车。在选择模式选中道路后，可用分开的按钮按差价升级或降级，也可拆除；选中区域或路线后，地图上还会显示无文字的 ↑ / ↓ / ⌫ 快捷按钮；桥面道路与普通道路相同。
      • 满载时车辆在上游排队，不会因拥堵直接判负。路口关闭红绿灯时，可按到达时间自动让行，或自定义北、东、南、西入口优先顺序，均以正常速度的 35% 逐车通过。启用红绿灯后可使用横向直行、横向左转、纵向直行、纵向左转自动循环，也可配置 1～8 个手动阶段、预览当前动作并按预计车流生成建议灯序；冲突组合可暂存并会标红，开始运营前必须按提示位置修正。右转不等灯，但要避让直行、左转及已进入路口的冲突车辆，出口满载时也要等待。互不冲突的车流可以同时通过。
      • 三岔 / 十字路口默认自动避让。路况与红绿灯只在开放这些功能的关卡可用；开放后点击路口，可选择无灯让行方式、排列入口优先级，或调整红绿灯的自动/手动阶段与绿灯时长。道路负荷显示最忙方向的占用率，路口显示四个冲突分区的预约率；普通道路每车道有前后两个位置。路口格内印有各进口的直行和左转箭头线：绿线放行，红线等待；右转浅色弯线表示让行通行。只显示已有出口，关闭信号后所有箭头线变为浅色。
      • 规划时住宅右上角显示总人口、目的地右上角显示接收容量；运营时分别实时显示尚未离开的居民和扣除已分配人数后的剩余容量。住宅左下角显示居民产生率，右下角“待”字气泡显示当前排队；住宅详情会提示汽车出口规则，并在地图高亮预计路径与最低速度瓶颈。
      • 公交线模式（5）：在公交教学关沿已有明确连接的道路分段绘制，每次从线路末端续画。普通线路须回到起点才会发车；也可开启原路返回并选择返程是否停站。运营前检查会提示无效线路，但不会阻止其他交通开始运行。线路允许重复道路；每辆公交消耗 6 点预算，容量 12 人，速度为道路小汽车速度的 1.35 倍，上下客每秒 8 人；多车按 2～8 秒间隔依次发车。线路完成后，邻近建筑的线路道路格自动设站；选择线路道路格可分别管理经过该格的各条线路站点，无需建筑道路出口连接。公交面板可管理线路名称、颜色、从末端反向擦除、清空重画、删除、车辆数、发车间隔、双向停站及逐线路突出/虚化；彩线靠右连续绘制，细箭头表示方向，自动返程段显示为同色虚线；公交只接走目的地也有站点且容量充足的居民，车顶人数标识实时显示载客量。
      • 准备好后点击「开始运营」；系统会先提示不可达住宅、容量不足、无效公交和理论送达上限，这些提示可忽略；手动红绿灯冲突必须按给出的地图位置修正后才能运行。在本关时限内达到运输目标即胜利。运营开始后规划会锁定，暂停时也只能查看路况；如需修改，请点击「停止运营」，道路、信号与公交线路设置会保留，车辆、车上乘客、成绩与计时会清空并返回规划。
      • 规划阶段可用“撤销 / 重做”按钮恢复最多 60 步道路、剪断、等级、信号灯或公交编辑，也可按 Ctrl/Command + Z 撤销，按 Ctrl/Command + Shift + Z 或 Ctrl/Command + Y 重做；运营期间暂时锁定，停止运营后可继续使用。
      • 「保存设计」会按关卡将当前道路、等级、汽车引导、信号和公交线路（含站点、班距及双向停站）设置保存在本浏览器中；「读取设计」会替换当前设计并重新进入规划。规划修改还会自动保存最近关卡与草稿，刷新后可从顶部一键继续；五日日期、收入、区域、支出和检查点也会恢复，但运行中的车辆与计时不会保存。「清除自动进度」不会删除手动设计或成绩。配置了参考答案的教程关卡会在首次失败后解锁“查看参考答案”；载入后仍需自行开始运营。
      • 运营时顶部会实时显示已经产生居民的满意度；居民等待或在途时间超过 8、15、25 秒会逐档下降，地图会在长时间排队的住宅、汽车、公交和换乘站旁显示居民表情与人数。结算时按完整通勤时间统计四档分布；已经产生但尚未抵达的居民按最低档计入满意度，并展示未产生、等待、汽车在途、公交在途与已抵达的人口守恒拆分。普通关卡中满意度仅用于展示。
      • 五日挑战会连续运营五天；进入关卡或新一天时，地图自动聚焦当前已开放的道路与建筑。未来区域覆盖半透明灰雾、保留隐约轮廓并显示可点击的锁；点击锁或灰雾可查看任务条件，达成后支付建设点开放，开放前不能建设。区域内建筑还要满足自身条件；同色住宅或目的地尚未成对启用时，人口或容量保持锁定，不参与目标和满意度。进度条可回到任一天运营前，并恢复当时的区域开放与支出。
      • 键盘：方向键移动光标，空格使用当前模式；1 / 2 / 3 / 4 / 5 切换观察、选择、拖拽、剪刀、公交线。选择模式按空格选择当前格；拖拽或剪刀用空格设起点、方向键延伸、空格结束；P 暂停。倍速按钮会依次切换 1×、2×、4×、0.5×；车辆、需求、信号灯和倒计时都会按所选倍速运行。
