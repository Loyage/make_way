GOD MODE GUIDE

管理员操作手册

管理员端现在就是一个权限更高的游玩面板：地图、工具、运营和玩家看到的完全一致，右侧城市控制台负责修改章节、关卡及关卡内定义。所有修改先进入草稿预览，明确发布前不会写入磁盘。

工作流章节关卡世界编辑路线建筑多日任务发布

统一工作流

  1. 在上方按普通玩家方式观察、规划道路并运行城市。
  2. 在右侧修改关卡定义。合法修改会立即重建当前城市，让管理员直接看到玩家实际体验。
  3. 用撤销、重做调整草稿；状态栏会持续进行服务器端结构校验。
  4. 确认后点击“保存并发布”。发布写入 levels.json 和 levels.local/，公开游戏服务重启后生效。

重建预览会清空当前运行和未捕获的玩家路网。要保留上方规划，请先点击“将当前玩家路网设为初始道路”。

章节与关卡

  • 控制台可新建、编辑和删除空章节；章节 ID 只能包含小写字母、数字和连字符。
  • 关卡可新建、复制、删除和调整同章顺序。关卡顺序就是玩家看到的顺序。
  • 关卡信息包含名称、标题、任务说明、提示、预算、时长、公交上限和功能开关；修改后直接以玩家界面预览。
  • 至少必须保留一个章节和一个关卡，每关至少保留一条完整路线。

地图与初始道路

  • 先用玩家工具栏切换“选择”，点击单格或拖出矩形；控制台会显示所选格子。
  • “空地 / 水面 / 桥梁 / 树木”批量修改选区。建筑格不能直接覆盖为地形；应先移动建筑。
  • 道路使用玩家的拖拽、剪刀、升级和降级工具编辑，因此操作结果与真实游戏完全一致。
  • 道路完成后必须点击“将当前玩家路网设为初始道路”，将道路等级和显式连接写回草稿。汽车引导、信号配置和公交线路属于玩家方案，不会成为关卡初始定义。

路线与建筑

  • 每条路线可设置名称、主色和浅色，并包含多个住宅和目的地。
  • 住宅配置格子索引、居民产生率和总人口；目的地配置标签和可选输入上限。
  • 可在建筑卡片直接填写格子索引，也可先选地图格，再点击“移动到地图所选首格”。
  • 目的地总接收能力必须覆盖同路线住宅总人口，建筑不能重叠、越界或位于水面和树木上。

多日任务

  • 启用后可设置 2～30 天的时长和最高收入；第 1 天时长同时作为关卡基础时长。
  • 路线与建筑编辑的是全部潜在建筑，草稿会同步生成第 1 天基础路线。
  • 展开每栋建筑的“解锁与升级”，可按日期、累计送达、累计收入和上一日满意度设置联合条件，并添加住宅人口/产生率或目的地输入上限的升级阶段。

草稿、校验与发布

  • 右侧橙点表示存在未发布草稿；绿色校验提示表示可发布。校验失败时先按具体错误修正。
  • 撤销与重做覆盖章节、关卡、参数、建筑和地形修改，最多保留 60 步。
  • “放弃草稿并重新载入”会恢复磁盘版本。“保存并发布”只在完整校验通过后写盘。
  • 游戏服务启动时会将静态资源读入内存，因此发布后需要重启 traffic-game.service 才能让公开玩家看到更新。

安全提醒：管理员服务默认监听所有网卡，密码是唯一访问防线。对外开放必须设置强密码；仅本机使用建议设置 ADMIN_HOST=127.0.0.1。
