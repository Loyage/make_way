管理员操作手册

管理员端现在就是一个权限更高的游玩面板：地图、工具、运营和玩家看到的完全一致，右侧城市控制台负责修改章节、关卡及关卡内定义。所有修改先进入草稿预览，明确发布前不会写入磁盘。

统一工作流

  1. 在上方按普通玩家方式观察、规划道路并运行城市。
  2. 在右侧修改关卡定义。合法修改会立即重建当前城市，让管理员直接看到玩家实际体验。
  3. 用撤销、重做调整草稿；状态栏会持续进行服务器端结构校验。
  4. 确认后点击“保存并发布”。发布写入 levels.json 和 levels.local/，公开游戏服务重启后生效。

重建预览会清空当前运行和未捕获的玩家路网。要保留上方规划，请先点击“将当前玩家路网设为初始道路”。

章节与关卡

  • 控制台可新建、编辑和删除空章节；章节 ID 只能包含小写字母、数字和连字符。
  • 关卡可新建、复制、删除和调整同章顺序。关卡顺序就是玩家看到的顺序。
  • 关卡信息包含名称、标题、任务说明、提示、预算、时长、公交上限、星级目标和功能开关；修改后直接以玩家界面预览。
  • 星级挑战中的通关星由完成运输目标自动判定；管理员配置满意度星阈值，以及效率星同时要求的最高建设点数和最大住宅排队人数。普通关卡使用关卡目标，多日任务还可逐日覆盖。
  • 至少必须保留一个章节和一个关卡，每关至少保留一条完整路线。

教程参考答案

  • 先使用上方玩家工具完成并验证教程关卡的方案，再点击“保存当前完整设计为参考答案”。
  • 参考答案保存道路、显式连接、等级、汽车引导、信号灯和公交线路；它不同于只保存初始路面的“将当前玩家路网设为初始道路”。
  • 玩家首次失败后才会看到“查看参考答案”，载入后仍停留在规划阶段，不会自动运营。
  • 多日任务暂不支持单一参考答案。修改地图、建筑或预算后应重新验证并保存答案；不再需要时可删除。

地图与初始道路

  • 先用玩家工具栏切换“选择”，点击单格或拖出矩形；控制台会显示所选格子。
  • “空地 / 水面 / 桥梁 / 树木”批量修改选区。建筑格不能直接覆盖为地形；应先移动建筑。
  • 道路使用玩家的拖拽、剪刀、升级和降级工具编辑，因此操作结果与真实游戏完全一致。
  • 道路完成后必须点击“将当前玩家路网设为初始道路”，将道路格等级和显式连接分别写入 initialRoads 与 initialEdges。汽车引导、信号配置和公交线路属于玩家方案，不会成为关卡初始定义。

路线与建筑

  • 每条路线可设置名称、主色和浅色，并包含多个住宅和目的地。
  • 住宅配置格子索引、居民产生率和总人口；目的地配置标签和可选输入上限。
  • 可在建筑卡片直接填写格子索引，也可先选地图格，再点击“移动到地图所选首格”。
  • 目的地总接收能力必须覆盖同路线住宅总人口，建筑不能重叠、越界或位于水面和树木上。

多日任务

  • 启用后可设置 2～30 天的时长、最高收入和逐日星级目标；第 1 天时长同时作为关卡基础时长。
  • 路线与建筑编辑的是全部潜在建筑，草稿会同步生成第 1 天基础路线。
  • 展开每栋建筑的“解锁与升级”，可按日期、累计送达、累计收入和上一日满意度设置联合条件，并添加住宅人口/产生率或目的地输入上限的升级阶段。

草稿、校验与发布

  • 右侧橙点表示存在未发布草稿；绿色校验提示表示可发布。校验失败时会一次列出发现的问题，点击问题可切换到对应关卡，并在带坐标时选中地图格。
  • 撤销与重做覆盖章节、关卡、参数、建筑和地形修改，最多保留 60 步。
  • 修改任一关卡后，先点击“验证并试玩”；结构校验通过后控制台会收起，必须用当前草稿实际通关。多日任务须完成最后一天。每个修改过的关卡都通过后，才可发布整份配置。
  • 试玩认证绑定当前关卡的完整版本。通关后只要继续修改该关，认证就会立即失效并重新阻止发布；撤销回已经通关的完全相同版本时，认证会恢复。
  • “放弃草稿并重新载入”会恢复磁盘版本。“保存并发布”只在完整校验和人工通关门禁均通过后写盘。
  • 游戏服务启动时会将静态资源读入内存，因此发布后需要重启 traffic-game.service 才能让公开玩家看到更新。

安全提醒：管理员服务默认仅监听 127.0.0.1，并会对连续失败登录短期封禁。对外开放必须显式设置 ADMIN_HOST、使用强密码并通过反向代理提供 HTTPS；代理终止 TLS 时同时设置 ADMIN_SECURE_COOKIE=1。
