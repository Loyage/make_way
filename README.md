# 慢行小城 · Little City

原生 HTML / CSS / JavaScript 交通规划小游戏。5 个自由选择的关卡，无构建步骤、无第三方依赖、无外部字体或图片请求。

## 本机游玩

直接用现代浏览器打开 **`index.html`**，即可完全离线游玩。

## 通过 IP + 端口访问

需要 Node.js 18+，在项目目录运行：

```sh
node server.js
```

默认监听所有 IPv4 / IPv6 网卡的 **8180** 端口：

- 本机：<http://127.0.0.1:8180>
- 远程：`http://服务器IPv4:8180`
- IPv6：`http://[服务器IPv6]:8180`

自定义监听地址和端口：`HOST=0.0.0.0 PORT=9000 node server.js`。

**远程访问还需要防火墙放行、可路由的 IP，以及可能的路由器端口转发。监听所有网卡不等于已经可以从互联网访问。**

持久用户服务安装：

```sh
bash deploy/install-service.sh
```

详见 **[部署与网络说明](deploy/README.md)**。服务只开放游戏静态资源，不公开项目目录。各玩家在自己的浏览器内独立运行游戏，不共享道路、车辆或关卡状态；不是多人同步联机。

## 五座小城

| 关卡 | 主题 | 出行组数 | 建设预算（点） | 时限 | 运输目标 |
| --- | --- | ---: | ---: | ---: | ---: |
| 01 晨光街区 | 无河流、学习基本连接 | 2 | 36 | 90 秒 | 22 辆 |
| 02 河畔新城 | 原版地图、双桥跨河 | 3 | 64 | 120 秒 | 35 辆 |
| 03 林间环城 | 绕行中央绿地、共享道路 | 4 | 46 | 110 秒 | 60 辆 |
| 04 双河群岛 | 两条河、错位桥梁 | 4 | 48 | 100 秒 | 75 辆 |
| 05 都会早高峰 | 五组密集出行、三桥分流 | 5 | 52 | 100 秒 | 110 辆 |

所有关卡均可自由选择，难度由地形、线路数量、发车间隔和目标共同决定。切换会重置本局；已有建设或正在运营时先弹出确认。胜利后可以前往下一关，最后一关可以重玩。

## 道路等级、容量与信号灯

| 等级 | 每格建设费用 | 速度（格/秒） | 每方向车道数 | 每方向容量（辆） |
| --- | ---: | ---: | ---: | ---: |
| 支路 | 1 点 | 2.8 | 1 | 2 |
| 干道 | 2 点 | 4 | 2 | 4 |
| 快速路 | 3 点 | 5.2 | 3 | 6 |

路面宽度随车道数增加，所有等级的车辆长宽一致，不再缩小车辆以塞入更多车道。每格每条车道有前后两个位置，后车先进入后位，前位空闲才可前进；移动期间保留源位置和目标位置预约，禁止穿过前车。

- 在地图下方选择等级，再沿相邻格拖动修路。单击不建路，只有拖动经过的格间才建立双向连接；相邻路面可以擦身而过，不会自动相连。同格交叉会形成平面路口。建筑出入口也需拖动接通；固定桥梁保留桥内连接，但桥与岸边需主动连接。
- **剪刀（4）**沿道路拖动，剪断经过的格间连接，保留两侧路面与等级，不返还预算；再沿断口拖动修路即可接回。拆除仍返还费用。车辆正在穿越或已预约的连接不能剪断。
- 道路升级仍通过选等级后沿已有道路拖动完成。升级只付差价，降级返还差价，拆除返还该道路的全部费用。桥梁的支路基础免费，也可付差价升级，但不能拆除。
- 车辆占用或已预约驶入的道路不能降级或拆除；可以安全升级。新关卡和重开都会恢复支路建设工具，清空等级及信号设置。
- 容量统计包含当前车辆和驶入预约；满载时车辆在上游等待，住宅也可能积压。各方向分别限额，并为同向车辆分配不同通行位置。不会因为拥堵直接判负，但排队会影响限时运输目标。
- 道路速度在混合等级交界处取较慢的一侧。寻路仍按最短格数，不是按旅行时间计算；升级短板、修建分流路线都能改善通行。
- 三岔与十字路口依据实际连接数识别（建筑出入口也计入分支），默认采用**自动避让**：到达路口前登记顺序、先到先行、逐车通过，进入与驶离路口时均按正常道路速度的 **50%** 行驶；出口满载时等待，其他具备通行条件的车辆可先行。该模式在繁忙路口效率较低。手动勾选「启用红绿灯」后，放行车辆按道路原速通过，不额外减速，但仍遵守红灯、冲突和容量限制。四阶段循环：**横向直行 → 横向左转 → 纵向直行 → 纵向左转**。默认每阶段绿灯 2 秒，阶段间有 0.25 秒直行/左转全红清空期；规划和暂停时信号计时也停止。
- 按车辆进入及离开路口的方向判断转向。**右转不受灯色限制**，但须避让可通行的直行/左转车辆及已经预约冲突区域的车辆；出口满载时仍等待。清空期也允许没有冲突的右转。
- 选择 **「路况 / 信号」**，点击路段查看车道及前后位置容量；点击路口可将每阶段绿灯改为 **2 / 4 / 6 秒**，或关闭信号灯。调整立即生效，已获准进入的车辆保持原转向和预约直到离开，不会因变灯突然停车或中途改向。
- 路口改为**四分区冲突预约**，不再整格仅限一车：对向直行、对向受保护左转及不冲突的右转可以并行。关闭信号灯则恢复半速、单车通行的自动避让。路口是通行空间，不按普通路段的前后车位排队；升级道路不会取消冲突约束。这是保守的简化冲突模型，不模拟全部真实车道转向组合。
- 已预约路口出口不能拆除或降级；相邻道路有人通行时，暂不能通过增删分支将其变为路口或取消路口。
- 「显示道路负荷」为道路加上绿 / 橙 / 红色边框，代表最忙方向的低负荷 / 接近满载 / 已满；路口显示四个冲突分区的预约率。红框不一定代表持续拥堵。路口不再使用小灯和文字标牌，而是在方格各进口一侧印上箭头线：直行与左转分别用绿线表示放行、红线表示等待；右转始终使用浅色弯箭头表示让行通行。只绘制实际存在的入口和出口，关闭信号后全部箭头变为浅色。车辆绘制在箭头线上方，侧栏仍提供完整阶段及倒计时说明。
- 切换自动避让与红绿灯须等待路口清空，避免已经进入的车辆失去安全约束。五关仍有预算内通关方案；参考方案按路线显式连接，并在繁忙路口手动启用信号灯，时限、目标、地图与预算未降低。
- 设计存档使用 v2 格式，保存道路及格间连接，包括剪断的位置；v1 旧存档按原来的相邻自动连通规则迁移，保留原信号选择。

这是离散格子交通模型；“快速路”是游戏中的道路等级，并非真实交通法规中的封闭快速路。

## 操作

- 鼠标或触摸拖动修路；选择「拆除」或使用右键拆路，返还道路额度。
- 拖动经过的上下左右格间才相连，建筑也必须拖动连接。河流只能通过固定桥梁，树林不可建设。
- 点击「开始运营」后，住宅持续产生车辆，车辆沿当前最短路线行驶。
- 在本关时限内达到运输目标即胜利。住宅角标是待出发车辆；同向车辆会在道路瓶颈处排队。
- 运营时也可建设和调灯。车辆占用及即将驶入的格子不能拆除或降级；修改其他道路后车辆会重新寻路。
- 「保存设计」按关卡将道路、等级与信号设置保存在当前浏览器；「读取设计」会替换当前方案并回到规划状态。运营车辆、成绩与计时不属于设计存档。
- 暂停时可继续规划。2× 同时加快车辆与计时。
- 「停止运营」保留当前设计，清空车辆、排队、成绩和计时，回到规划阶段以便重新尝试。
- 切到后台、打开帮助或重开/切关确认时自动暂停，需要手动继续。

| 快捷键 | 操作 |
| --- | --- |
| `1` / `2` / `3` / `4` | 修路 / 拆除 / 路况与信号 / 剪刀 |
| `P` | 开始、暂停、继续 |
| 方向键 | 地图获得焦点后移动格子光标 |
| 空格 | 修路或剪刀：设定起点，再用方向键延伸，空格或 Esc 结束；其他工具：在当前格使用 |

## 开发与测试

```sh
node --test tests/*.test.js
node --check game.js
node --check server.js
```

测试覆盖原版逻辑、全部关卡的数据有效性与可通关性、独立状态、暂停与停止运营、设计存档校验和往返读取、等级差价、各级速度与容量、红灯等待、全红切换、路口冲突与占道保护，以及 HTTP 资源白名单、路径遍历防护、并发请求、HEAD 和缓存。

可选浏览器集成测试需要 Node.js 22+ 和 Chromium，无需 npm 依赖。先启动游戏服务，再将本机 Chromium 以 `--headless --remote-debugging-port=9333 --user-data-dir=/tmp/traffic-game-browser` 启动，执行 `node tests/browser-smoke.cjs`。它验证设计保存/读取、停止运营并重新规划、关卡切换确认、暂停重开、胜负结算、下一关边界、道路升级返还、路口信号设置、手机布局和触摸升级；可通过 `GAME_URL` / `CDP_URL` 指定地址。调试端口只应在本机开放，测试后关闭调试浏览器。

```text
index.html                  中文界面、关卡选择、弹窗
style.css                   响应式样式
levels.js                   5 个不可变的关卡定义
core.js                     DOM 无关的地图和模拟引擎
game.js                     Canvas 绘图与交互
server.js                   零依赖只读 HTTP 服务
tests/*.test.js             自动化测试
tests/browser-smoke.cjs      可选浏览器集成测试
deploy/install-service.sh   用户服务安装脚本
deploy/traffic-game-network.nix  NixOS 防火墙与 linger 配置
```

没有账户、排行榜或服务器端游戏状态；设计存档仅保存在当前浏览器的 `localStorage` 中，每个关卡一个，不包含运营成绩。刷新会回到第一关，可通过「读取设计」恢复该关方案。车辆使用按方向限容、通行位置预约和路口分区冲突预约规则，并非真实交通工程仿真。
