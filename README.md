# 慢行小城 · Little City

原生 HTML / CSS / JavaScript 交通规划小游戏。5 个自由选择的关卡，无构建步骤、无第三方依赖、无外部字体或图片请求。

## 本机游玩

直接用现代浏览器打开 **`index.html`**，即可完全离线游玩。

## 通过 IP + 端口访问

需要 Node.js 18+，在项目目录运行：

```sh
node server.js
```

默认监听所有 IPv4 / IPv6 网卡的 **8180** 端口：

- 本机：<http://127.0.0.1:8180>
- 远程：`http://服务器IPv4:8180`
- IPv6：`http://[服务器IPv6]:8180`

自定义监听地址和端口：`HOST=0.0.0.0 PORT=9000 node server.js`。

**远程访问还需要防火墙放行、可路由的 IP，以及可能的路由器端口转发。监听所有网卡不等于已经可以从互联网访问。**

持久用户服务安装：

```sh
bash deploy/install-service.sh
```

详见 **[部署与网络说明](deploy/README.md)**。服务只开放游戏静态资源，不公开项目目录。各玩家在自己的浏览器内独立运行游戏，不共享道路、车辆或关卡状态；不是多人同步联机。

## 五座小城

| 关卡 | 主题 | 出行组数 | 道路预算 | 时限 | 运输目标 |
| --- | --- | ---: | ---: | ---: | ---: |
| 01 晨光街区 | 无河流、学习基本连接 | 2 | 36 | 90 秒 | 22 辆 |
| 02 河畔新城 | 原版地图、双桥跨河 | 3 | 64 | 120 秒 | 35 辆 |
| 03 林间环城 | 绕行中央绿地、共享道路 | 4 | 46 | 110 秒 | 60 辆 |
| 04 双河群岛 | 两条河、错位桥梁 | 4 | 48 | 100 秒 | 75 辆 |
| 05 都会早高峰 | 五组密集出行、三桥分流 | 5 | 52 | 100 秒 | 110 辆 |

所有关卡均可自由选择，难度由地形、线路数量、发车间隔和目标共同决定。切换会重置本局；已有建设或正在运营时先弹出确认。胜利后可以前往下一关，最后一关可以重玩。

## 操作

- 鼠标或触摸拖动修路；选择「拆除」或使用右键拆路，返还道路额度。
- 道路上下左右相连，紧邻建筑即可接通。河流只能通过固定桥梁，树林不可建设。
- 点击「开始运营」后，住宅持续产生车辆，车辆沿当前最短路线行驶。
- 在本关时限内达到运输目标即胜利。住宅角标是待出发车辆；同向车辆会在道路瓶颈处排队。
- 运营时也可建设。车辆占用及即将驶入的格子不能拆除；修改其他道路后车辆会重新寻路。
- 暂停时可继续规划。2× 同时加快车辆与计时。
- 切到后台、打开帮助或重开/切关确认时自动暂停，需要手动继续。

| 快捷键 | 操作 |
| --- | --- |
| `1` / `2` | 修路 / 拆除 |
| `P` | 开始、暂停、继续 |
| 方向键 | 地图获得焦点后移动格子光标 |
| 空格 | 在光标格子使用工具 |

## 开发与测试

```sh
node --test tests/*.test.js
node --check game.js
node --check server.js
```

测试覆盖原版逻辑、全部关卡的数据有效性与可通关性、独立状态、暂停、预算、寻路、占道保护，以及 HTTP 资源白名单、路径遍历防护、并发请求、HEAD 和缓存。

可选浏览器集成测试需要 Node.js 22+ 和 Chromium，无需 npm 依赖。先启动游戏服务，再将本机 Chromium 以 `--headless --remote-debugging-port=9333 --user-data-dir=/tmp/traffic-game-browser` 启动，执行 `node tests/browser-smoke.cjs`。它验证关卡切换确认、暂停重开、胜负结算、下一关边界、手机布局和触摸操作；可通过 `GAME_URL` / `CDP_URL` 指定地址。调试端口只应在本机开放，测试后关闭调试浏览器。

```text
index.html                  中文界面、关卡选择、弹窗
style.css                   响应式样式
levels.js                   5 个不可变的关卡定义
core.js                     DOM 无关的地图和模拟引擎
game.js                     Canvas 绘图与交互
server.js                   零依赖只读 HTTP 服务
tests/*.test.js             自动化测试
tests/browser-smoke.cjs      可选浏览器集成测试
deploy/install-service.sh   用户服务安装脚本
deploy/traffic-game-network.nix  NixOS 防火墙与 linger 配置
```

没有账户、存档、排行榜或服务器端游戏状态，刷新会回到第一关。车辆使用简化双向车道预约规则，并非真实交通工程仿真。
