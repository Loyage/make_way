LEVEL EDITOR GUIDE

管理员操作手册

用于创建、校验、仿真和发布关卡配置。建议先另存配置备份，再编辑并保存；玩家服务会在启动时载入资源，发布后还需重启游戏服务。

章节与关卡基础参数路线与建筑地图编辑多日任务撤销与校验仿真保存与发布

章节与关卡

  • 左侧可新建章节和关卡；关卡顺序就是玩家界面的课程序号。
  • 章节可修改名称、英文名和 id。仅空章节可删除，含关卡时需先移动或删除其中关卡。
  • 关卡可复制、删除、移动到其他章节，或用上下按钮调整同章顺序。所有 id 只能使用小写字母、数字和连字符，且必须唯一。

基础信息与地图尺寸

  • 名称、英文名、难度、课时名、标题、描述和提示都会显示给玩家，请完整填写。
  • 预算按道路格等级和公交车辆扣除；时长单位为秒；关卡目标自动等于所有住宅人口之和，无需单独填写。
  • 地图宽高可设为 8～64 格。应用新尺寸时内容按中心保持位置；若建筑会越界，调整会被拒绝，其他越界地形或道路可能被裁剪。
  • 功能开关决定玩家能否使用道路等级、负荷、剪刀、路况、信号灯和公交。公交线路上限可设为 1～6。

路线与建筑

  • 每条路线至少包含一个住宅和一个目的地，并使用名称、主色和浅色区分。
  • 住宅设置居民产生率和总人口；目的地设置标签及可选输入上限。不同建筑不能重叠，也不能位于水面或树木上。
  • 坐标以地图中心为原点：向右为 +x，向上为 +y。可直接修改坐标，也可先选择当前路线及住宅/目的地，再用地图工具放置。
  • 目的地总输入容量必须容纳对应路线的全部住宅人口；输入容量留空表示不限。

地图编辑与整体挪动

  • 观察工具用于拖动地图；普通滚轮滚动页面，按住 Ctrl 滚动或触控板双指捏合才缩放地图。水面、桥梁、树木、住宅、目的地和初始道路工具用于绘制，地图外观与游戏画面保持一致。桥梁必须位于水面上。
  • 初始道路按当前道路等级绘制，连接必须逐段明确建立；相邻格不会自动连通。擦除工具会删除地形、道路或连接。
  • “整体挪动”按中心坐标同时移动地形、初始道路、基础路线和五日任务建筑。任一内容越界时整次移动取消。

连续五日任务

  • 启用后必须配置正好五天。每天可分别设置运营时长、最高收入、路线及建筑；当日目标自动等于当日住宅总人口。
  • 基础路线和时长始终与第 1 天同步。可复制前一天配置，或将当前配置复制到下一天后再调整。
  • 未来日期新增建筑会作为灰色工地预览；不要让初始道路占用这些工地。

撤销、重做与校验

  • 面板保留最多 60 步编辑历史。点击页首“撤销 / 重做”，或使用 Ctrl/Command + Z、Ctrl/Command + Shift + Z。
  • 连续拖动画图作为一步记录。重新载入磁盘或载入另一份配置会建立新的历史起点。
  • 编辑后会自动校验；也可点击“立即校验”。必须处理红色错误后才能保存，错误通常会指出具体章节、关卡、日期或坐标。

初始道路仿真

  • 选择关卡和日期后点击“开始仿真”，可用 1×、2×、4×、0.5× 切换速度，观察送达、时间、在途车辆和住宅等待。
  • 仿真直接使用游戏核心规则，但只测试当前配置中的初始道路，不会修改关卡数据。
  • 开始编辑会自动停止仿真。仿真通过不代表所有玩家方案都可通关，仍需结合预算、总人口和关卡测试检查。

保存、备份与发布

  1. 先用“另存为配置”创建不可重名的备份；“载入配置”会替换当前未保存内容。
  2. “保存到 levels.json”写入玩家关卡覆盖层；“覆盖默认配置”会直接改写 built-in-levels.json，操作前务必确认。
  3. 保存成功后重启游戏服务，再打开玩家界面核对章节、关卡和实际玩法。游戏服务启动时会把静态资源读入内存，不重启不会看到更新。

安全提醒：管理员面板默认监听所有网卡，密码是唯一访问防线。对外开放时必须设置强密码；仅本机使用时建议设置 ADMIN_HOST=127.0.0.1。
